<h1 align="center">🎬 Flutter Movie Streaming App</h1>

<p align="center">
  <strong>A cross‑platform movie streaming app built with Flutter & Dart, powered by Firebase.<br>Browse, search, and stream movies in real time — with authentication, favorites, and a modern UI.</strong>
</p>

---

## 🌟 Features

- 🎥 **Real‑Time Movie Streaming** – stream movies directly from Firebase Storage  
- 🔐 **User Authentication** – sign up, log in, and manage profiles with Firebase Auth  
- 📚 **Dynamic Catalog** – browse, search, and filter movies across multiple categories  
- ⭐ **Favorites & Watchlist** – save movies to watch later, synced across devices  
- 📱 **Responsive UI** – works seamlessly on both Android and iOS  
- ☁️ **Cloud Backend** – Firestore for metadata, Firebase Storage for video content  

---

## ⚙️ Technologies Used

| Layer          | Technology / Plugin |
|----------------|---------------------|
| **Framework**  | Flutter (Dart) |
| **Backend**    | Firebase Auth, Firestore, Cloud Storage |
| **State Management** | Provider / Bloc |
| **Video Playback** | video_player plugin |
| **Deployment** | Android & iOS via Firebase Hosting / App Stores |

---

## 📄 How It Works

1. Firebase stores all **movie metadata** (titles, descriptions, posters) and **video files**.  
2. Users register and log in securely through **Firebase Authentication**.  
3. The app fetches the movie catalog from **Firestore** in real‑time.  
4. Users can **stream** movies, **add to favorites**, or **browse categories** — all interactions sync live.  
5. Every action is persisted in Firebase, so the experience follows the user across devices.
